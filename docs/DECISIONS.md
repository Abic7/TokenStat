# TokenStat Decisions

Version 0.1 | Date 2026-11-17 | Author Abi Chaudhuri | Status Current

Purpose: Architecture decisions, why, and what would reverse them. Evidence from Windows research pass G-01 (2026-11-17) unless noted.

| ID | Decision | Why | Reverse if | Status |
|---|---|---|---|---|
| ADR-01 | Data source: Claude Code status line hook only | Only documented source of allowance %; read-only; no credentials | Spike D-01 shows no rate_limits for Team seats | Accepted by maintainer, pending spike |
| ADR-02 | Rust with `windows-sys` raw Win32 bindings. No winit, tray-icon or notify. | Smallest footprint. windows-sys 0.61.2 is MIT OR Apache-2.0 with one runtime dependency (windows-link), verified on crates.io 2026-11-17. Higher-level crates add an event loop the app does not need. | Hand-written Win32 code grows past ~1,000 lines | Accepted |
| ADR-03 | Add `windows` crate (0.62.2, MIT OR Apache-2.0) only for the screen reader provider | UI Automation needs COM; windows-sys does not wrap COM | A plain window title proves enough for Narrator in testing | Proposed |
| ADR-04 | One thread, one message loop waiting on: window messages, folder-change event, one waitable timer | Zero polling, zero periodic wakeups | Measured CPU or latency misses budget | Accepted |
| ADR-05 | Pill: borderless popup, tool window (no taskbar button), topmost, drag by hit-test, Windows 11 rounded-corner hint | Matches Q-04. Rounded corners on frameless windows are only a hint; may need a drawn shape. | n/a | Accepted, corners to test |
| ADR-06 | Text with GDI, not Direct2D | Small static text; Direct2D creates a GPU device per factory (Learn). Memory difference unmeasured. | Pill needs animation or GDI text looks poor at 150 to 200% scaling | Accepted (reversible) |
| ADR-07 | Logo and tray icon: twin rings (outer weekly, inner session) on a dark rounded square. Tray rings fill with live %, coloured by level, grey when stale. Drawn in code (src/icon.rs), no image files at run time. | maintainer chose concept A 2026-11-17. Digits at 16 px are unreadable. | Rings unreadable on real taskbar | Accepted |
| ADR-08 | Snapshot written as temp file then atomic rename; watcher filters for snapshot.json | Watcher never reads a half-written file | Rename not detected in test | Accepted, to test |
| ADR-09 | Single exe with `--statusline` mode first; split into a tiny hook exe only if it misses 100 ms | Simpler install; measure before optimising | Measured wall time over 100 ms | Accepted |
| ADR-10 | Launch at sign-in via per-user Run registry entry, off by default | Simplest for unpackaged app; visible in Task Manager Startup tab | n/a | Accepted |
| ADR-11 | Code signing deferred | Costs money; needs maintainer approval. Unsigned exe is scanned by Defender each launch, which may slow statusline mode, especially from a OneDrive path. | Measured statusline time over budget due to scanning | Deferred, needs approval |
| ADR-12 | Install to `%LOCALAPPDATA%\Programs\TokenStat`, not the OneDrive project folder | OneDrive paths scan slower (Learn); keeps build output out of sync | n/a | Accepted |
| ADR-13 | Pill follows Windows light/dark app setting by reading `AppsUseLightTheme` in the current user's Personalize registry key; repaints on settings change. High contrast overrides both. | maintainer asked for light and dark support. Registry read is tiny and needs no WinRT. The value is widely used but its documentation on Learn is unverified. | Value moves or stops updating; switch to WinRT UISettings | Accepted |
| ADR-14 | Each % coloured on its own: under 75% normal, 75% amber, 90% and above red. Labels stay plain. | maintainer asked for usage-based colour; one high value should not colour the other | maintainer wants different thresholds | Accepted |
| ADR-15 | Exe icon embedded with embed-resource 3.0.12 (MIT, build-time only, verified on crates.io 2026-11-17) from assets/tokenstat.ico | Explorer and Task Manager show the logo | Build fails on the maintainer's machine | Accepted |
| ADR-16 | Cover VS Code extension use: a Claude Code hook (documented to run in IDE extensions) tells TokenStat when Claude replies; pill shows 'used since' at once; TokenStat then runs a hidden, tiny Claude Code request to fetch fresh figures, rate-limited. No credential handling, no undocumented services. | maintainer requires extension and terminal coverage (2026-11-17). Statusline does not run in the extension (A-09); local cache is stale (S-08). | Spike D-02 shows the hidden request cannot return figures | Accepted by maintainer, pending spike D-02 |
| ADR-17 | VS Code auto-refresh is opt-in, off by default. Enabling it shows the impact (allowance use, background work, admin visibility, undocumented field) and needs confirmation. Menu shows refreshes and tokens used today. Uses the undocumented `unifiedWindows` field of Claude Code's `rate_limit_event`; parsed defensively, shows unavailable if missing. Hidden request runs with `--safe-mode --tools ""` in an empty folder, max once per 5 min, backs off on failure. | maintainer approved 2026-11-17 | Field removed, or measured cost too high | Accepted |
| ADR-18 | System stats are whole-system figures, each off by default, toggled in a System stats submenu, appended after the Claude figures. Pill is free-shape: drag the left or right edge to set the width; items (Session, Weekly, each stat) wrap into rows and the height follows. Width saved; Reset size returns to one row. | maintainer asked for user-chosen shape 2026-11-17 | n/a | Accepted |
| ADR-19 | Stats sample every 2 s only while at least one is on and the pill is visible; sampling and the GPU query stop when hidden. Breaks Phase 1's zero-periodic-wakeup target only while stats are on. | Rates (CPU, network, GPU) need periodic samples | Measured idle cost too high | Accepted (PM call) |
| ADR-20 | Sources: CPU from GetSystemTimes; RAM from GlobalMemoryStatusEx (used physical memory %); network from GetIfTable2, physical adapters that are up, excluding loopback and filter drivers; GPU from the documented PDH counter `\GPU Engine(*)\Utilization Percentage`, summed per engine type and busiest type shown (Task Manager style, approximate). Hide labels applies to all items, including CPU, RAM and GPU (maintainer 2026-11-17); network arrows stay. | All documented Win32 APIs, no new dependencies | GPU figure disagrees with Task Manager by more than a few points | Accepted (PM call) |
